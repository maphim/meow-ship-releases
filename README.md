# Meow Ship — Releases

APK chính thức của **Meow Ship** (quản lý đơn giao hàng chung cư).

## Tải bản mới nhất

- Trang: https://github.com/maphim/meow-ship-releases/releases/latest
- Hoặc trong app: **Cài đặt → Cập nhật & chia sẻ bản cài → Copy link tải APK**
- Hoặc trong **Meow Net → Ứng dụng → Meow Ship → Copy link APK**

Mỗi release có asset `MeowShip-<versionCode>.apk`. Cài đè bản cũ (cùng khoá ký) là giữ dữ liệu.
